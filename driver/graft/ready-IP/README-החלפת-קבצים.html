4 בנה

למעלה: ודא Release. ואז Build ← Build Solution (Ctrl+Shift+B).

אם הצליח — ה-.pkg נוצר תחת bin\Release\.

⚠ שגיאות בנייה? זה צפוי בפעם הראשונה פתח למטה Error List, העתק את הטקסט של השגיאות (או צלם), ושלח לי. אלה הדברים הסבירים ביותר:
  • Newtonsoft.Json לא נמצא → נוסיף חבילת NuGet.
  • System.Net.Sockets לא נתמך → אמיר את התעבורה ל-CrestronSockets.
  • net472 targeting pack חסר → נשנה ל-net48.
אל תתקן לבד — שלח לי, וזה מהיר.
