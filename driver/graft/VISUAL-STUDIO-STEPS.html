1 סגור את "Create a new project"

⚠ לא יוצרים פרויקט חדש! במסך שפתחת ("Create a new project") — לחץ על ה-X בפינה כדי לסגור. אנחנו פותחים את פרויקט הדוגמה הקיים, לא יוצרים חדש.

2 פתח את פרויקט הדוגמה

File ← Open ← Project/Solution…

נווט לתיקייה:

mila-claude-crestron-paradox-integration-t1ufg9\Crestron SDK Folder\

ובחר את הקובץ שמתחיל ב-SecuritySystem_Crestron_SampleDriverModel_IP (קובץ הפרויקט של Visual Studio) → Open.

ℹ אם קופצת בקשה להחזיר חבילות (Restore NuGet) — אשר. אלה חבילות ה-SDK (DevKit + ManifestUtil).

3 (מומלץ) בנה פעם אחת "כמו שזה"

לפני שנוגעים בקוד — ודא שהפרויקט המקורי נבנה אצלך. זה קו-הבסיס הבטוח:

למעלה: שנה Debug ל-Release  ·  ואז Build ← Build Solution (Ctrl+Shift+B)

אם למטה מופיע Build: 1 succeeded — מצוין, אפשר להמשיך.

6 בצע את עריכות הקוד

עכשיו נבצע את השתילה עצמה — פתיחת קבצי הדוגמה ועריכתם לפי המדריך המפורט. כל בלוק קוד שם מוכן להעתקה:

📄 פתח את INTEGRATION.html (המדריך ששלחתי קודם) ובצע את שלבים ב'–ו':
  • ב' — SecuritySystemDriverIP.cs: שורה אחת (קריאה ל-StartEngine).
  • ג' — SecuritySystemProtocol.cs: הלב (using, שדות, StartEngine, מטפלי אירועים, DataHandler, ExecuteSecurityCommands, Dispose).
  • ד' — SecuritySystemZone.cs: מתודה אחת.
  • ה' — SecuritySystemArea.cs: שתי מתודות.
  • ו' — SampleTransport.cs: הפוך לפסיבי.
כדי לפתוח קובץ לעריכה — דאבל-קליק עליו ב-Solution Explorer.
