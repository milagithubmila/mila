# 02 — חיווט חומרה

## רכיבים נדרשים
1. לוח Paradox (EVO192 / SP / MG / DGP-848 …).
2. מודול **APR-PRT3** (Printer Module).
3. אחד מהשניים:
   - **ממיר Serial↔Ethernet** (מומלץ): Lantronix UDS1100/XPort, Moxa NPort,
     USR-TCP232-302 וכד'. מאפשר לחבר את ה-PRT3 לרשת ולגשת מ-CP4-R ב-TCP.
   - **חיבור טורי ישיר**: רק אם יש לבקר/לסביבה COM פנוי וקרוב פיזית.
4. כבלים ומתח ל-PRT3 (מוזן מה-AUX של הלוח, או ספק נפרד).

## חיבור PRT3 ↔ לוח Paradox
חבר את ה-PRT3 ל-Serial של הלוח לפי הוראות Paradox (חיבור Combus/Serial בהתאם לדגם).
ודא הזנת מתח תקינה (אדום=AUX+, שחור=AUX−, ירוק/צהוב=Combus) לפי המדריך של הלוח.

## חיבור PRT3 ↔ ממיר Serial↔Ethernet (RS-232)
ל-PRT3 יציאת RS-232 (מחבר/פינים מסומנים TX/RX/GND). חיבור **Null-modem הפוך**:

```
   APR-PRT3            ממיר Serial↔Ethernet
   ─────────           ────────────────────
   TX  ───────────────►  RX
   RX  ◄───────────────  TX
   GND ───────────────   GND
```

> שים לב: TX של צד אחד מתחבר ל-RX של הצד השני (cross). אם אתה רואה echo אך
> לא מקבל תשובות — סימן מובהק ש-TX/RX הפוכים.

הגדרות הפורט בשני הצדדים חייבות להיות זהות:
**57600 bps, 8 data bits, No parity, 1 stop bit (8N1), ללא בקרת זרימה.**
(אם הסביבה רועשת/ארוכה אפשר לרדת ל-19200 או 9600 — ובלבד ששני הצדדים תואמים,
וגם הגדרת ה-PRT3 עצמה, ראה `docs/03`.)

## הגדרת הממיר (דוגמה כללית)
1. הגדר לממיר **כתובת IP סטטית** ברשת הניהול של הבית (למשל `192.168.1.50`).
2. הגדר את הפורט הטורי: **57600 8N1**, no flow control.
3. הגדר מצב **TCP Server (Raw/Transparent)** על פורט (ברירת מחדל נפוצה `10001`).
4. כבה כל "Telnet/COM-Port-Control" אם קיים — אנחנו רוצים זרם בייטים שקוף.

> רשום את ה-IP והפורט — תזדקק להם בהגדרת הדרייבר ב-Crestron (`docs/06`)
> ובכלי האבחון (`docs/04`).

## חיבור CP4-R לרשת
ודא ש-CP4-R והממיר באותה רשת/VLAN ושיש נתיב ביניהם (אותו subnet, או routing מתאים).
מומלץ להניח את הממיר ואת ה-CP4-R ב-VLAN ניהול/בקרה מבודד.

## בדיקת קצה-לקצה לפני Crestron
חבר מחשב לאותה רשת והרץ את כלי האבחון (`docs/04`):

```bash
cd gateway
python3 cli.py monitor --tcp 192.168.1.50:10001 --zones 1-8 --areas 1
```

הזז יד מול גלאי — אמורה להופיע שורה `[ZONE 00x] ... -> OPEN`. אם כן —
החומרה והפרוטוקול תקינים, וניתן לעבור לבניית הדרייבר.
