# 03 — תכנות מודול APR-PRT3

מטרת השלב: להעביר את ה-PRT3 למצב **ASCII (Home Automation)** במהירות **57600 8N1**,
כדי שיגיב לבקשות `RZ`/`RA` וישדר סטטוס גלאים/מחיצות.

> ⚠️ מספרי **כתובות התכנות (sections)** ב-PRT3 **שונים בין דגמי לוח** (EVO מול
> SP/MG מול DGP-848). אל תסתמך על מספרים מהזיכרון — פתח את החוברת
> *"APR3-PRT3 — ASCII Protocol Programming Instructions"* המתאימה לדגם שלך
> וודא את הכתובת המדויקת. להלן ה**מה** שצריך להגדיר; ה**איפה** (section)
> מצוין בחוברת.

## מה צריך להגדיר ב-PRT3

1. **בחירת פרוטוקול = ASCII**
   ל-PRT3 כמה מצבי עבודה: *Printer*, *C-Bus*, ו-*ASCII*. בחר **ASCII**.
   (במצב Printer הוא רק מדפיס לוג; אנחנו צריכים ASCII דו-כיווני.)

2. **מהירות הפורט הטורי = 57600 bps** (8N1).
   ודא שזו אותה מהירות שהגדרת בממיר (`docs/02`).

3. **הפעלת דיווח אירועי Home Automation**
   הפעל את האפשרות שמשדרת/מאפשרת שאילתות סטטוס לגלאים ולמחיצות
   (לעיתים מסומן "Serial events" / "Home Automation events"). זה מה שמאפשר
   ל-`RZ`/`RA` להחזיר מצב עדכני.

4. **(אם נדרש) הקצאת מחיצות/גלאים לדיווח**
   בחלק מהדגמים מגדירים אילו מחיצות מדווחות דרך ה-PRT3. ודא שהמחיצות
   והגלאים הרלוונטיים כלולים.

5. **קודי משתמש לדריכה/נטרול (אופציונלי)**
   אם תרצה שהדרייבר ידרוך/ינטרל (`AA`/`AD`), הכן **קוד משתמש** ייעודי
   ל-Crestron בלוח. תזין אותו בהגדרות הדרייבר (`UserPin`).

## הגלאים — נקודה קריטית לפרויקט הזה
המטרה היא לזהות **תנועה**. ודא שהגלאים הרצויים:
- מחווטים ומוגדרים כ-Zones תקינים בלוח Paradox.
- מדווחים מצב פתוח/סגור (Open/Closed) דרך ה-PRT3 (בדיקה: `RZnnn` מחזיר `O` בזמן תנועה).

> **שים לב להתנהגות גלאי PIR:** גלאי תנועה מדווח `Open` לזמן קצר בזמן זיהוי
> ואז חוזר ל-`Closed`. הדרייבר/האוטומציה צריכים להתייחס ל-**מעבר ל-Open**
> כ"זוהתה תנועה" ולהתחיל/לאפס את הטיימר — ולא לצפות שה-Open יישאר דולק.
> לוגיקה זו כבר ממומשת (ראה `docs/07`).

## אימות התכנות
לאחר התכנות, חבר מחשב לממיר והרץ (`docs/04`):

```bash
cd gateway
python3 cli.py monitor --tcp <ip-של-הממיר>:10001 --zones 1-8 --areas 1
```

- אם אתה רואה שינויי `OPEN/CLOSED` בזמן תנועה → PRT3 מוגדר נכון.
- אם אין כלום אך החיווט תקין → בדוק מצב ASCII ומהירות 57600, ושה-TX/RX לא הפוכים.
- אם מקבלים `&fail` על פקודות → בדוק שהמחיצה/הגלאי קיימים ושהקוד (אם נשלח) תקין.
