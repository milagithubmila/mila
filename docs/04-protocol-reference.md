# 04 — פירוט פרוטוקול ה-ASCII של PRT3

מקור: *Paradox APR3-PRT3 — ASCII Protocol Programming Instructions*.
זהו הפרוטוקול שהדרייבר ו-`gateway/` מממשים.

## עקרונות
- כל הודעה (בקשה ותשובה) מסתיימת ב-**CR בודד** = `\r` = ASCII **13** (0x0D).
- תקשורת טורית **8N1**, מהירות 2400/9600/19200/**57600** (אנו ב-57600).
- כל פקודה זוכה ל-**echo/ack**: חמשת התווים הראשונים של הפקודה, ואחריהם:
  - `&ok`  — פקודה תקינה.
  - `&fail` — פקודה שגויה.
  - או **המידע המבוקש** עצמו, כשמדובר בשאילתת מידע (`RZ`/`RA`).

## פקודות שאנו שולחים

| פקודה | פורמט | דוגמה | משמעות |
|-------|-------|-------|--------|
| בקשת סטטוס גלאי | `RZnnn` | `RZ005` | מהו מצב גלאי 5? |
| בקשת סטטוס מחיצה | `RAnnn` | `RA001` | מהו מצב מחיצה 1? |
| דריכה | `AAnnn<m><PIN>` | `AA001A1234` | דריכת מחיצה 1, מצב A, קוד 1234 |
| נטרול | `ADnnn<PIN>` | `AD0011234` | נטרול מחיצה 1, קוד 1234 |

`nnn` = שלוש ספרות עם אפסים מובילים. מצבי דריכה `<m>`:
`A`=רגיל, `F`=Force, `S`=Stay/חלקי, `I`=Instant.

## תשובת סטטוס גלאי — `RZ`

```
R Z n n n s . . . .
        │   │
        │   └─ תו סטטוס (מיקום 6, אינדקס 5)
        └───── מספר גלאי (3 ספרות, מיקומים 3-5)
```

| תו | מצב | פירוש | "תנועה"? |
|----|-----|-------|:--------:|
| `C` | Closed | סגור / ללא תנועה / תקין | לא |
| `O` | Open | פתוח / תנועה זוהתה | **כן** |
| `T` | Tamper | חבלה/ניתוק | כן |
| `F` | Fire | לולאת אש | כן |

דוגמה: `RZ005O\r` → גלאי 5 פתוח (תנועה). `RZ005C\r` → גלאי 5 סגור.
(חלק מהקושחות מוסיפות תווי דגלים נוספים אחרי תו הסטטוס — הם נתעלמים מהם.)

## תשובת סטטוס מחיצה — `RA`

```
R A n n n A . . . . X .
        │   │         │
        │   │         └─ תו אזעקה (מיקום 11, אינדקס 10)
        │   └─────────── תו דריכה (מיקום 6, אינדקס 5)
        └─────────────── מספר מחיצה (3 ספרות)
```

| שדה | תו | משמעות |
|-----|----|--------|
| דריכה | `D` | מנוטרל (Disarmed) |
| דריכה | `A` | דרוך (Armed) |
| אזעקה | `O` | אין אזעקה (Ok) |
| אזעקה | `A` | באזעקה (In Alarm) |

דוגמה: `RA001A----A-\r` → מחיצה 1 דרוכה **ובאזעקה**.
`RA001D----O-\r` → מחיצה 1 מנוטרלת, ללא אזעקה.

## אישורים — `&ok` / `&fail`
דוגמה: שליחת `AA001A1234\r` → תשובה `AA001&ok\r` (דריכה הצליחה) או
`AA001&fail\r` (קוד/מחיצה שגויים).

## פסאודו-זרימה של המנוע
```
לכל גלאי ז ב-Zones:
    שלח "RZ{ז:000}\r"
    קרא שורה → פענח → אם השתנה מהמצב הקודם: הפעל אירוע ZoneChanged
לכל מחיצה מ ב-Areas:
    שלח "RA{מ:000}\r"
    קרא שורה → פענח → אם השתנה: הפעל אירוע AreaChanged
המתן PollInterval (~400ms) וחזור
```

## אימות עצמאי (ללא Crestron)
```bash
cd gateway
python3 cli.py monitor --tcp 192.168.1.50:10001 --zones 1-8 --areas 1
# פלט לדוגמה:
# [ZONE 005] ZoneState.CLOSED -> OPEN
# [AREA 001] arm=armed alarm=ok
```

לבדיקת לוגיקת הפענוח עצמה (ללא חומרה):
```bash
cd gateway && python3 -m unittest test_paradox_prt3 -v   # 22 passed
```
