# 06 — הטמעה ב-Crestron Home (Setup App)

לאחר שיש לך קובץ `.pkg` (`docs/05`), זהו שלב ההוספה וההגדרה ב-Crestron Home.

> המסכים המדויקים משתנים מעט בין גרסאות Crestron Home. הזרימה הכללית קבועה.

## שלב 1 — טעינת הדרייבר ל-CP4-R
1. פתח את **Crestron Home Setup App** והתחבר לפרויקט (לבקר CP4-R).
2. עבור אל **Settings → Drivers** (או "Manage Drivers" / "Custom Drivers",
   לפי הגרסה).
3. בחר **Load/Add Custom Driver** והעלה את הקובץ
   `Mila_SecuritySystem_Paradox_PRT3_IP.pkg`.
4. הדרייבר יופיע ברשימת הדרייברים הזמינים.

## שלב 2 — הוספת ההתקן
1. עבור אל **Rooms / Devices → Add Device**.
2. בחר קטגוריה **Security** (או "Sensors", בהתאם לאופן שהדרייבר חושף את עצמו).
3. בחר את הדרייבר **Paradox PRT3 (Mila)**.
4. בהגדרות החיבור הזן:
   - **Host** = כתובת ה-IP של ממיר ה-Serial↔Ethernet (למשל `192.168.1.50`).
   - **Port** = `10001` (או מה שהגדרת בממיר).
   - **UserPin** = קוד משתמש לדריכה/נטרול (אם תרצה לדרוך/לנטרל מ-Crestron).
   - **Zones** = רשימת הגלאים לסקירה, CSV (למשל `1,2,5,8`).
   - **Partitions** = רשימת המחיצות (למשל `1`).
   - **PollIntervalMs** = `400` (ברירת מחדל סבירה).

## שלב 3 — אימות תקשורת
1. ודא שהדרייבר מציג **Online/Connected**.
2. הזז יד מול גלאי — מצב ה-Zone המתאים אמור להשתנות ל-Open ואז לחזור ל-Closed.
3. דרוך/נטרל את המערכת — מצב ה-Partition ב-Crestron אמור לעקוב.

> אם offline: בדוק רשת/IP/פורט, ושכלי ה-Python מצליח להתחבר לאותו host:port
> (`docs/04`). אם ה-Python עובד וה-Crestron לא — הבעיה ברשת/הגדרות הדרייבר.

## שלב 4 — מיפוי הגלאים לחדרים
1. שייך כל **Zone** לחדר הרלוונטי (Assign to Room).
2. תן שמות ברורים (כניסה, סלון-תנועה, מחסן-תנועה …) — אלה השמות שתבחר
   מהם באוטומציה.
3. סמן גלאי תנועה כ-**Motion/Occupancy** וגלאי דלת/חלון כ-**Door/Window**
   (אם הדרייבר/ה-UI מאפשר סוג גלאי).

## שלב 5 — להמשיך לאוטומציה
כעת הגלאים והמחיצות זמינים כ"טריגרים" במנוע האוטומציה.
המשך ל-**`docs/07`** לבניית "תנועה → אור → טיימר".
